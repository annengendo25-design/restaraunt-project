# KWETU HOTEL 🍝

## Project Overview

Kwetu Hotel is a simple restaurant and café website created using HTML and CSS. The website provides information about the hotel, displays different food and drink options, and allows customers to place an order through the online order page.

## Features

* 🏠 Home section with an introduction to Kwetu Hotel
* ✍🏾 About Us section
* 🍽️ Menu section with different categories
* ☕ Beverages menu
* 🥘 Food menu
* 🍲 Kids menu
* 🧇 Breakfast menu
* 📞 Contact Us section
* 🛒 Order Now button
* 📱 Social media links
* 📧 Email contact
* 📱 Responsive design for different screen sizes

## Technologies Used

* HTML5
* CSS3
* Font Awesome

## Website Sections

### Home

The Home section introduces visitors to Kwetu Hotel and explains what the café offers.

### About Us

The About Us section provides information about the background and purpose of Kwetu.

### Menu

The Menu section displays different food and beverage options using images and descriptions.

### Contact Us

The Contact Us section provides the hotel's contact information and links to social media platforms.

### Ordering

Customers can click the **Order** link in the navigation bar or the **Order Now** button to access the ordering page.

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Use Live Server to view the website in your browser.
5. Navigate through the different sections using the navigation links.

## Accessibility

The website uses alternative text (`alt`) for food images and `aria-label` attributes for icon-based social media links to improve accessibility.
